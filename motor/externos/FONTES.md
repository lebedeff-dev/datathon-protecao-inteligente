# Fontes externas do motor

Todas são públicas. O motor lê os CSVs desta pasta e **não acessa a internet enquanto roda**. SINAPI e IPCA são renovados pelas APIs oficiais com `python motor/externos/coletar.py --ao-vivo`; se a API falhar, o CSV salvo continua valendo, com a data de referência. Sem um arquivo, ele usa um valor neutro e baixa a confiança. As cópias dos documentos originais estão em `referencias/fontes/`.

## Hierarquia de confiança das fontes (revisão de 29/10)
| Nível | Fontes | Uso permitido |
|---|---|---|
| 1 · Oficial com API | SINAPI (IBGE/SIDRA), IPCA (Banco Central/SGS) | Valor (faixas), atualizado por `coletar.py --ao-vivo` |
| 2 · Oficial sem API | CUB (Sinduscons), Atlas/S2iD (MIDR), ranking ANEEL (gov.br), Condições Gerais BB | Valor (CUB) ou só texto (Atlas, ANEEL) |
| 3 · Privada reconhecida | FipeZAP (Fipe) | Valor da perda de aluguel de quem mora no próprio imóvel |
| 4 · Secundária | Sinistros BB (matéria de imprensa) | **Só contexto no texto**; nunca valor, plano ou confiança |
